# Agent Discipline (API phases)

`api-invariants.mdc` and approved backend spec/contract win on conflict.

- State assumptions; ask when unclear; prefer simpler approaches.
- Minimum code for the request; no speculative features or abstractions.
- Surgical edits only; match existing style; do not refactor unrelated code.
- Record `openQuestions` in spec instead of silent guesses.
- Define verifiable success criteria; run scoped verification before claiming done (`verify-gate.md`).
