# Common API response envelope

Standard success/error payload shape for all API Base endpoints (ApiResponse).

- **Source YAML:** `docs/features/common/common-api-response.yaml`

## contract

```yaml
success:
  type: object
  required:
    - success
    - code
    - message
    - data
  properties:
    success:
      type: boolean
      example: true
    code:
      type: integer
    message:
      type: string
    user_message:
      type: string
      nullable: true
    data:
      description: Resource, collection, or null
    meta:
      description: Optional — pagination, etc.
    trace_id:
      type: string
      nullable: true
error:
  type: object
  properties:
    success:
      example: false
    code:
      type: integer
    error:
      type: string
    message:
      type: string
    errors:
      description: Field errors for 422
    trace_id:
      type: string
      nullable: true
```

## pagination

```yaml
location: meta.pagination
fields:
  - current_page
  - per_page
  - last_page
  - total
```
